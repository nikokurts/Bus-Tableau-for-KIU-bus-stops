# Bus-Tableau-for-KIU-bus-stops
Project for my university which is meant to approximately tell when the city municipal busses arrive at university stops.

This is a frontend focused project. At the moment it is just html/css, only XX:00 and XX:30 formatted times are available to enter and is rather small. Though in the finals we know that we have to update it so with Javascript I plan to have it be able to accept any time from user, thus being more accurate, plus perhaps a bit more livelier design. It should be said that adding Javascript will only make project easier to finalise, as it will definitely shorten some development processes along the way.
